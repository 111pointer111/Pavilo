# Pavilo / 语亭

> 一条命令，给身边的人一间聊天室。

Pavilo 是一个浏览器即用、默认临时、可以自行托管的极简群聊项目。名字取自 **Pavilion + Local**：像一座随处可搭的小亭，让同一网络中的人打开网页就能交谈。

项目长期目标是成为一个轻量但完善的多频道聊天室。当前版本为 **v0.1 Alpha**，只提供一个实际可用的公共频道，适合可信局域网、私有网络或 VPN 环境。

## 设计原则

- **开箱即用**：安装 Node.js 后，一条命令即可启动，参与者只需要浏览器。
- **保持轻量**：当前服务端只使用 Node.js 内置模块，没有运行时第三方依赖。
- **临时优先**：默认不使用数据库、不写入聊天记录，停止服务即清空会话。
- **部署者可控**：服务运行在自己的电脑或服务器上，不依赖外部账号和云服务。
- **按需扩展**：持久化、权限与风控未来作为可选能力加入，不让默认部署变重。

## 当前功能

- 使用用户名进入 `general` 频道
- 发送文字、常用表情和图片
- 支持 PNG、JPEG、GIF、WebP，单张图片最大 1.5 MB
- 回复已有消息，显示精确到秒的发送时间
- 随机生成头像，点击头像查看成员信息
- 在线成员列表、加入与离开提示、输入状态提示
- WebSocket 断线自动重连
- 响应式移动端布局、键盘操作和减少动态效果支持
- `/healthz` 健康检查接口

> 多频道目前仍是产品目标，界面中的其他频道入口尚未开放，详见 [ROADMAP.md](./ROADMAP.md)。

## 环境要求

- Node.js 22 或更高版本
- 支持 WebSocket 的现代浏览器

## 快速开始

```bash
npm start
```

默认监听 `0.0.0.0:4173`。启动后终端会打印本机与可用的局域网地址：

- 本机访问：`http://localhost:4173`
- 局域网访问：`http://<主机局域网 IP>:4173`

把局域网地址发给连接同一 Wi-Fi 或私有网络的用户即可。使用其他端口：

```bash
PORT=8080 npm start
```

停止服务请按 `Ctrl-C`。

## 在服务器上运行

Pavilo 可以运行在能够执行 Node.js 的服务器上，但 **v0.1 只面向可信网络**。推荐通过内网、VPN 或其他已经具备访问控制的私有网络访问。

当前版本没有内建账号认证、TLS、端到端加密或完整的安全风控，也没有针对公网攻击完成系统性加固。请勿把端口直接暴露到公网。

## 数据与隐私边界

- 会话、在线状态和消息只保存在 Node.js 进程内存中。
- 服务端最多保留最近 300 条消息，进程结束或重启后全部清空。
- 浏览器仅通过 `sessionStorage` 保存当前标签页的头像种子，不保存聊天记录；关闭标签页后头像种子也会消失。
- 当前成员资料会向同一频道的参与者显示连接 IP，因此只应在彼此信任的环境中使用。隐藏或配置化 IP 已列入近期加固计划。
- 服务端会限制用户名、文字与图片大小，并进行基础发送频率限制；这些措施不能替代完整的认证与风控系统。

## 项目状态

Pavilo 仍处于早期 Alpha 阶段。现有代码验证了“无需安装客户端即可快速建立临时聊天室”的核心体验，但多频道、可选持久化、自动化测试和公网安全基线尚未完成。

路线图遵循“先稳定核心，再增加能力”的顺序，且不承诺固定发布日期。具体计划见 [ROADMAP.md](./ROADMAP.md)。
