# Pavilo / 语亭

> 一条命令，给身边的人一间聊天室。

Pavilo（**Pavilion + Local**）是一个浏览器即用、默认临时、可以自行托管的极简群聊。像一座随处可搭的小亭：启动 Node.js 进程，同一局域网里的人打开网页就能交谈，服务停止后一切回到空白。

当前版本 **v0.1 Alpha**：单频道、零运行时依赖、仅内存存储，适合可信局域网、私有网络或 VPN 环境。

## 设计原则

- **开箱即用**：安装 Node.js 后一条命令启动，参与者只需要浏览器。
- **保持轻量**：服务端只使用 Node.js 内置模块，没有任何运行时第三方依赖。
- **临时优先**：不使用数据库、不写入聊天记录，停止服务即清空会话。
- **部署者可控**：运行在自己的电脑或服务器上，不依赖外部账号和云服务。
- **按需扩展**：持久化、权限与风控作为未来可选能力加入，不让默认部署变重。

## 功能

**聊天体验**

- 输入用户名即可进入 `general` 频道
- 文字、常用表情、图片（PNG / JPEG / GIF / WebP，单张上限 1.5 MB）
- 回复消息，每条消息显示精确到秒的发送时间
- 随机生成头像，点击头像查看用户名、IP、在线时长
- 在线成员列表、加入/离开提示、输入状态提示
- 六种轻量消息回应：👍 ❤️ 😂 🎉 👀 🔥
- 响应式移动端布局、键盘操作与减少动态效果支持

**可靠性**

- 消息由服务端确认接收（ACK），未确认或失败的内容可在当前页面重试
- 相同消息 ID 幂等去重，断线重连自动恢复临时身份
- 图片发送前在浏览器内按需缩放压缩（GIF 保留动画）
- 服务重启产生新的房间纪元，旧的未确认内容不会自动发入新房间

**提醒（渐进式）**

- 页内未读计数与“回到底部”按钮、标题未读角标、动态图标徽标
- “开启提醒”只会在用户点击后请求浏览器通知权限，绝不自动弹窗
- 普通局域网 HTTP 地址即使无法使用系统通知，页内提醒也始终可用

## 快速开始

```bash
npm start
```

默认监听 `0.0.0.0:4173`，启动后终端会打印本机与局域网访问地址：

- 本机访问：`http://localhost:4173`
- 局域网访问：`http://<主机局域网 IP>:4173`

把局域网地址发给连接同一 Wi-Fi 或私有网络的用户即可。更换端口：

```bash
PORT=8080 npm start
```

停止服务请按 `Ctrl-C`。

## 可靠的边界（建议先读）

**消息 ACK** 表示“本次服务进程已接受”，不表示所有成员已送达或已读。默认容量包括：最多 300 条历史、约 32 MB 房间消息预算、单图 1.5 MB、80 个连接、同一 IP 12 个连接，以及慢连接写缓冲上限；超限时优先淘汰最旧消息。

**临时数据**：会话、在线状态、消息、未确认发送和回应都只存在于服务端进程或当前浏览器页面内存中；浏览器不使用 `localStorage`、`sessionStorage`、IndexedDB 或 Cache Storage 保存任何聊天内容。

**提醒边界**：系统通知需要浏览器权限与安全上下文，`http://<局域网 IP>` 通常不可用，此时自动降级为页内提醒。浏览器权限本身由浏览器管理，服务停止后仍可能存在。

## 在服务器上运行

Pavilo 可以运行在能执行 Node.js 的服务器上，但 **v0.1 只面向可信网络**（内网、VPN 或其他有访问控制的私有网络）。当前没有账号认证、TLS、端到端加密或完整的公网风控，请勿把端口直接暴露到公网。

成员资料会向频道内参与者显示完整连接 IP，这是已确认的产品选择，请只在可信环境中使用。

## 开发与测试

```bash
npm test        # 运行 Node 原生 HTTP / WebSocket 协议测试
node --check server.js
```

测试覆盖：历史分块同步、ACK 与幂等去重、重连会话、Origin 校验、心跳超时、reaction、启动/停止生命周期等。
