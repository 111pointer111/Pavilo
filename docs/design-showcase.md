# Pavilo 设计展示

> 一个专注于"临时、轻盈、可信"的现代聊天室设计

## 🎨 设计理念

Pavilo 的设计围绕产品核心概念构建：**像一座随处可搭的小亭，临时、轻盈、可信赖**。

### 三大核心原则

**1. 临时性（Ephemeral）**
- 半透明背景与玻璃态效果强化"只在此刻"的概念
- 柔和的阴影暗示"浮在空中"的轻盈感
- 微妙的脉冲动画提醒这只是当下的存在

**2. 可信赖（Trustworthy）**
- 清晰的视觉层级和信息架构
- 高可读性的字体组合（衬线标题 + 无衬线正文 + 等宽技术元素）
- 明确的状态反馈与交互提示

**3. 现代克制（Modern & Restrained）**
- 精心调校的青绿色主调（#0f7772）建立品牌识别
- 一致的圆角和间距规范（基于 4px 网格）
- 有节制的动效使用，尊重 `prefers-reduced-motion`

## 🌟 视觉亮点

### 双主题支持

完整支持浅色和深色两种主题，自动根据系统偏好切换：
- **浅色模式**：柔和的青绿色渐变 (#eef4f2) + 深青色主色 (#0f7772)
- **深色模式**：深邃的青黑色 (#0d1b1d) + 明亮青色主色 (#4dd4c7)

所有颜色对比度符合 WCAG AA 标准。

### 玻璃态美学

采用现代玻璃态设计（Glassmorphism），通过半透明背景和模糊效果营造轻盈感：

```css
/* 主工作区 */
background: rgba(249, 251, 248, .64);
backdrop-filter: blur(24px) saturate(180%);
```

这种设计强化了 Pavilo "临时聊天室"的核心概念——像一座半透明的小亭，轻盈、通透、不留痕迹。

### 微交互动画

每个交互都有精心设计的反馈：

- **按钮弹性反馈**：Hover 时轻微上浮 + 缩放，使用 `cubic-bezier(.68, -0.55, .27, 1.55)` 曲线实现弹性效果
- **脉冲动画**：连接状态指示器 2 秒周期的呼吸动画
- **表情交互**：选择表情时弹跳动画 (scale 1 → 1.3 → 1)，让每次表达都充满趣味

### 独特的图形语言

**不对称圆角头像**
```css
border-radius: 10px 10px 10px 3px;  /* 右下角更尖锐 */
```
这个独特的形状是 Pavilo 的视觉标识，在所有头像和品牌元素上保持一致。

**频道激活指示器**
激活的频道在左侧显示一条渐变色指示器，带有微妙的光晕效果。

## 🎯 设计决策背后的思考

### 为什么选择青绿色？

1. **差异化**：大多数聊天应用使用蓝色或紫色
2. **情感联系**：青绿色给人清新、自然、平静的感觉
3. **可读性**：在浅色和深色背景下都保持良好对比度

### 为什么用玻璃态？

1. **概念契合**：半透明感强化"临时"概念
2. **视觉层次**：模糊效果自然区分前后景
3. **现代感**：符合当代设计趋势

### 为什么强调微交互？

1. **愉悦感**：流畅的动画让使用变得有趣
2. **反馈明确**：动画提供即时的状态确认
3. **品牌个性**：独特的交互方式建立记忆点

## 📱 响应式体验

### 移动端优化
- 触摸优化：所有按钮最小 44×44px
- Tap highlight：半透明青色反馈
- Active 缩放：触摸时 scale(.97) 提供物理感
- 安全区适配：完整支持刘海屏和圆角屏

### 桌面端增强
- Hover 微交互：鼠标悬浮的细腻反馈
- 键盘导航：完整的 Tab 顺序和焦点样式
- 多级阴影：区分不同层级的界面元素

## 🌟 品牌识别点

### Logo 元素
- **亭子造型** + **通知圆点**
- 颜色：Teal (#0f7772) + Coral (#e86f57)
- 可在任何背景上使用

### 独特的色彩搭配
青绿色主调在聊天应用中非常少见，建立强烈的品牌识别度。

### 三种字体组合
- **Display**（衬线）：标题、品牌名 - 优雅有文化气息
- **Body**（无衬线）：正文、界面 - 现代清晰
- **Mono**（等宽）：技术元素、时间戳 - 精确专业

三种字体的组合创造了专业而有温度的阅读体验。
