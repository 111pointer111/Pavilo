# Pavilo 设计展示

> 一个专注于"临时、轻盈、可信"的现代聊天室设计

## 🎨 设计亮点

### 1. 双主题支持

Pavilo 完整支持浅色和深色两种主题，自动根据系统偏好切换。

**浅色模式**
- 背景：柔和的青绿色渐变 (#eef4f2)
- 主色：深青色 (#0f7772) - 代表沉稳与可信赖
- 强调色：珊瑚红 (#e86f57) - 温暖友好

**深色模式**
- 背景：深邃的青黑色 (#0d1b1d)
- 主色：明亮青色 (#4dd4c7) - 在深色背景下更清晰
- 保持所有功能的可读性和对比度

### 2. 玻璃态美学（Glassmorphism）

采用现代玻璃态设计，通过半透明背景和模糊效果营造轻盈感：

```css
/* 主工作区 */
background: rgba(249, 251, 248, .64);
backdrop-filter: blur(24px) saturate(180%);
```

这种设计强化了 Pavilo "临时聊天室"的核心概念——像一座半透明的小亭，轻盈、通透、不留痕迹。

### 3. 微交互动画

每个交互都有精心设计的反馈动画：

**按钮弹性反馈**
- Hover：轻微上浮 + 缩放 + 阴影增强
- Active：回弹效果
- 使用 `cubic-bezier(.68, -0.55, .27, 1.55)` 曲线实现弹性效果

**脉冲动画**
- 连接状态指示器：2秒周期的呼吸动画
- 登录页旗帜：吸引注意但不喧宾夺主
- 临时提示卡片：6秒一次的微妙闪烁

**表情交互**
- 选择表情时：弹跳动画 (scale 1 → 1.3 → 1)
- 反应按钮：悬浮时缩放 1.08 倍
- 让每次表达都充满趣味

### 4. 独特的图形语言

**不对称圆角头像**
```css
border-radius: 10px 10px 10px 3px;  /* 右下角更尖锐 */
```
这个独特的形状是 Pavilo 的视觉标识之一，在所有头像和品牌元素上保持一致。

**频道激活指示器**
```
┌────────────────┐
│ ▌# general    │  ← 左侧渐变条
└────────────────┘
```
激活的频道在左侧显示一条渐变色指示器，带有微妙的光晕效果。

### 5. 动效时序系统

统一的动画时长和缓动曲线确保视觉一致性：

```css
--transition-fast: 150ms    /* 即时反馈 */
--transition-base: 250ms    /* 标准过渡 */
--transition-slow: 400ms    /* 复杂动画 */

--ease-smooth: cubic-bezier(.4, 0, .2, 1)          /* 流畅 */
--ease-bounce: cubic-bezier(.68, -0.55, .27, 1.55) /* 弹性 */
```

## 🎯 设计原则在实际中的体现

### "临时性" 的视觉化

1. **半透明元素** - 像水汽一样易散
2. **闪烁动画** - 提醒这只是当下的存在
3. **柔和阴影** - 浮在空中的轻盈感

### "可信赖" 的建立

1. **清晰的信息层级** - 重要信息永远清晰可读
2. **一致的交互反馈** - 每个操作都有明确响应
3. **充足的对比度** - 符合 WCAG AA 标准

### "现代克制" 的平衡

1. **有节制的动画** - 只在需要时使用，尊重 `prefers-reduced-motion`
2. **精心调校的色彩** - 不超过 3 种主色
3. **统一的间距规范** - 基于 4px 网格系统

## 📱 响应式体验

### 移动端优化

- **触摸优化**：所有按钮最小 44×44px
- **Tap highlight**：半透明青色反馈
- **Active 缩放**：触摸时 scale(.97) 提供物理感
- **安全区适配**：完整支持刘海屏和圆角屏

### 桌面端增强

- **Hover 微交互**：鼠标悬浮的细腻反馈
- **键盘导航**：完整的 Tab 顺序和焦点样式
- **多级阴影**：区分不同层级的界面元素

## 🌟 品牌识别点

### 1. Logo 元素
- **亭子造型** + **通知圆点**
- 颜色：Teal (#0f7772) + Coral (#e86f57)
- 可在任何背景上使用

### 2. 色彩搭配
独特的青绿色主调在聊天应用中非常少见，建立强烈的品牌识别度。

### 3. 字体组合
- **Display**（衬线）：标题、品牌名
- **Body**（无衬线）：正文、界面
- **Mono**（等宽）：技术元素、时间戳

三种字体的组合创造了专业而有温度的阅读体验。

## 💡 设计决策背后的思考

### 为什么选择青绿色？

1. **差异化**：大多数聊天应用使用蓝色或紫色
2. **情感联系**：青绿色给人清新、自然、平静的感觉
3. **可读性**：在浅色和深色背景下都保持良好对比度

### 为什么用玻璃态？

1. **概念契合**：半透明感强化"临时"概念
2. **视觉层次**：模糊效果自然区分前后景
3. **现代感**：符合 2025 年的设计趋势

### 为什么强调微交互？

1. **愉悦感**：流畅的动画让使用变得有趣
2. **反馈明确**：动画提供即时的状态确认
3. **品牌个性**：独特的交互方式建立记忆点
