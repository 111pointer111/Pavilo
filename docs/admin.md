# 语亭管理后台

`/admin` 是给部署者的值班台，不走聊天会话。用 `operator.token` 登录。聊天页仍是给进亭的人用的。

房间与聊天频道可以在页面里改；第一次保存某段之后，该段以 SQLite 为准。模型渠道仍然只在 AI 网关模块配置。真源规则见 [ADR-0007](adr/0007-pavilion-config-overlay.md)。

## 产品分层

```text
语亭管理（本后台）
├── 总览              房间是否在跑，以及各段真源
├── 房间              标题、语言、默认频道、全站人数上限
├── 聊天频道          启用、欢迎语、只读、人数
└── 模块
    └── AI 网关
          ├── 网关总览
          ├── 模型渠道（不是聊天频道）
          └── 用量
```

两套「频道」不要混：

| 词 | 指什么 | 在哪改 |
| --- | --- | --- |
| 聊天频道 | `general` / `project` 那种房间里的频道 | 默认 YAML；管理页保存后以数据库为准 |
| 模型渠道 | DeepSeek / OpenAI 兼容供应商 | 只在「AI 网关 → 模型渠道」 |

AI 网关是语亭后台里的一个模块，不是另一套登录、另一套进程。审核、玩法以后同样以模块挂进来，仍然共用 operator session。

## 真源

- 从未在管理页保存：有效配置 = YAML（及代码默认值）。
- 保存房间 → 只认领房间段（标题、语言、默认频道、是否暴露 IP/LAN、`server.maxUsers`）。
- 保存聊天频道（含增删）→ 认领整个频道目录。
- 认领后 YAML 同段被忽略，启动时若文件与数据库不一致会警告。不回写 YAML。
- 「恢复为配置文件」删除该段 overlay，立刻套回 YAML，下次启动继续读文件。
- 监听地址、sqlite 路径、operator token、`plays` 模块列表永远在 YAML。
- memory 模式没有 `/admin`，继续只认 YAML。

保存后当前进程立刻使用新值。`/room-info`、新加入、切频道马上生效。已打开的聊天页不推新协议事件，刷新或重新进亭后看到新标题和频道列表。

## 交互原则

- 语亭总览回答「亭还在不在」；网关总览回答「模型通不通」。
- 房间/聊天频道表单打开时填入当前有效值（YAML 或已认领的数据库），并展示真源徽章：配置文件或管理页（数据库）。不是空白表。载入失败时提示错误，不要让管理员从空表开始改。
- 能点进每一项。不要做成带图标墙的 SaaS 后台。
- 写配置仍然分真源：YAML 管怎么启动；房间/聊天频道可被管理页按段认领；模型 key 只在网关模块进 SQLite。
