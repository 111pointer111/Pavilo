# 语亭管理后台

`/admin` 是给部署者的值班台，不走聊天会话。用 `operator.token` 登录。聊天页仍是给进亭的人用的。

本期（v1.3）只把**壳子**和 **AI 网关模块**落地。房间设置、聊天频道管理等语亭模块只预留页面，实现放到后续版本。

## 产品分层

```text
语亭管理（本后台）
├── 总览              现在就能看房间是否在跑
├── 房间              预留：标题、语言、限额
├── 聊天频道          预留：启用、欢迎语、只读、人数
└── 模块
    └── AI 网关       v1.3 已交付
          ├── 网关总览
          ├── 模型渠道（不是聊天频道）
          └── 用量
```

两套「频道」不要混：

| 词 | 指什么 | 在哪改 |
| --- | --- | --- |
| 聊天频道 | `general` / `project` 那种房间里的频道 | 现在 YAML；以后在「聊天频道」页 |
| 模型渠道 | DeepSeek / OpenAI 兼容供应商 | 只在「AI 网关 → 模型渠道」 |

AI 网关是语亭后台里的一个模块，不是另一套登录、另一套进程。审核、玩法以后同样以模块挂进来，仍然共用 operator session。

## 路由（hash）

| Hash | 模块 | 本期 |
| --- | --- | --- |
| `#/overview` | 语亭总览 | 可用：房间健康摘要 + 模块入口 |
| `#/room` | 房间 | 预留页，不写配置 |
| `#/chat` | 聊天频道 | 预留页，不写配置 |
| `#/gateway` | 网关总览 | 可用 |
| `#/gateway/channels` | 模型渠道列表 | 可用 |
| `#/gateway/channels/new` | 添加模型渠道 | 可用 |
| `#/gateway/channels/:id` | 编辑模型渠道 | 可用 |
| `#/gateway/usage` | 网关用量 | 可用 |

旧地址 `#/channels`、`#/usage` 会规范化到 `#/gateway/...`。

## 交互原则

- 语亭总览回答「亭还在不在」；网关总览回答「模型通不通」。
- 预留页说明**以后能做什么**和**现在为什么不能改**（改 YAML 并重启），不放假表单。
- 能点进预留页，避免导航里的项像坏掉的链接。
- 写配置仍然分真源：YAML 管怎么启动；模型 key 只在网关模块进 SQLite。以后房间/聊天频道若改成页面可编辑，另开 ADR，不在本期偷偷热加载 YAML。

## 布局

左侧账本式导轨，按「语亭 / AI 网关」分组。预留项带「稍后」标记，比现行项更淡。右侧仍是纸页：标题、一句说明、内容。不要做成带图标墙的 SaaS 后台。
